Como comparar

Se o grupo escolhido tiver menos imóveis que o mínimo, o site amplia sozinho: bairro, depois cidade, depois todo o site.

Média do m² hoje no seu site

Calculada com preço ÷ área dos imóveis publicados. É o que o site usa para comparar.

Referência de mercado por bairro (opcional)

Use quando o bairro tiver poucos imóveis no seu site. Uma por linha: Bairro | valor do m². Ex.: Jardins | 18500. Só entra se o site não tiver imóveis suficientes para comparar.
